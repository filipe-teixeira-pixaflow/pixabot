# Pixabot

Pixabot is a GitHub-driven automation assistant built for Pixaflow teams. The repository hosts reusable GitHub Actions workflows and helper scripts that keep pull requests transparent and responsive. Current capabilities include posting rich Slack notifications whenever a PR is opened or merged, so reviewers have instant context and links to take action.

## Features
- **Slack PR alerts** – announces new PRs with title, author, branches, repo, and description.
- **Merge celebrations** – updates the channel when a PR is merged, including the merger and summary.
- **Quick actions** – provides direct buttons to view or approve PRs from Slack.

Stay tuned for more automations as Pixabot evolves to streamline the Pixaflow development workflow.
